# Module 4 Issue-Driven Workflow Practice

Module 4 introduces the workflow:

**Issue → Branch → Pull Request → Close Issue**

Use this file for a small documentation change tied to one of your Module 4 Issues.

## Suggested Small Changes

Your Issue may propose a change such as:

- add a useful Git/GitHub term and definition
- improve or clarify an instruction
- add a short troubleshooting tip
- correct wording or formatting
- add a small resource or example

Keep the work small and specific.

## Git & GitHub Quick Reference

### Repository
A project and its version history stored with Git.

### Branch
A separate line of work used to make changes without directly changing `main`.

### Commit
A recorded set of changes in the repository history.

### Pull Request
A proposal to merge changes from one branch into another.

### Issue
A tracked item used to describe a feature, bug, task, or other unit of work.
